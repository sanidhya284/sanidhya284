## Featured Project

### URL Shortener with Asynchronous Analytics

A full-stack URL shortener designed to keep redirects independent of background analytics processing.

- **Asynchronous processing:** Offloads click analytics and GeoIP enrichment to BullMQ workers.
- **Rate limiting:** Uses Redis token buckets to enforce different limits for anonymous, free, and pro users.
- **Authentication:** Implements RS256-signed JWTs with access and refresh tokens.
- **Engineering practices:** TypeScript, API validation with Zod, Jest/Supertest, and GitHub Actions CI.

**Tech stack:** TypeScript, Node.js, Express, Next.js, MongoDB, Redis, BullMQ.
